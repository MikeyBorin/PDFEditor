Overview

PDF Editor is a Windows desktop app for viewing, annotating, editing, converting, and OCR-ing PDFs. Free for personal and non-commercial use under the PolyForm Noncommercial License 1.0.0. Commercial use requires a separate licence — see the About & licences section. Built on permissive open-source libraries (MIT / Apache 2.0) so there's no subscription and no external service dependency.

The app is organised around three surfaces:

  • The menu bar (File / Edit / Page / Tools / View / Help) for occasional actions.
  • The toolbar below the menu for tools and common commands (fully customisable).
  • The main viewer with a thumbnail sidebar on the left and a bookmarks/search panel on the right.

Getting started

Open a PDF in any of these ways:

  • Drag a .pdf file onto the window.
  • File → Open (Ctrl+O).
  • File → Open Recent — the last 10 files you opened.
  • Pass a path on the command line: PDFEditor.exe C:\path\to\file.pdf.
While a PDF is open, the app holds a read/share lock on the file so other apps can read but not overwrite it. Closing the file or the app releases the lock.

Viewing & navigation

  • Continuous scroll. All pages render vertically; scroll with the mouse wheel or scrollbar.
  • Zoom. The toolbar zoom combo accepts either a fit mode (Fit Width, Fit Page, Actual Size) or a percentage (25 – 1600%). Fit Width is the default on open. Actual Size (100%) means the true physical size — an A4 page displays at ~8.3 × 11.7 inches on screen. The same modes are also under View → Fit Width / Fit Page / Actual Size (each shows a ✓ next to the active mode). Your choice is saved per-user and restored on next launch.
  • Zoom keyboard. Ctrl++ / Ctrl+− bump the custom percentage. Ctrl+0 resets to Actual Size.
  • Thumbnail sidebar (left). Click a thumbnail to jump; scrolling the main view updates the highlight.
  • Page number box. Type any page number and press Enter to jump.
  • Prev / Next page. Toolbar buttons or keyboard.
  • Bookmarks / outline (right panel). Reads the PDF's outline tree; double-click a node to jump.

Search

Type a query into the search box (Ctrl+F) and hit Enter. Results appear in the right panel with page numbers.

  • Click any hit to jump; the match is briefly highlighted in yellow.
  • F3 — next hit. Shift+F3 — previous hit.
  • Tools → Redact Search Results paints black bars over every current hit and flattens them into the PDF. (Visual redaction; the text bytes still exist in the content stream — see Limitations.)

Annotation tools

All annotation tools live on the toolbar. Pick a tool, then click or drag on the page. Every annotation you create is an overlay — it lives on top of the pages until you Save, at which point it flattens into the PDF (sticky notes are the one exception; they're written as native PDF Text Annotations so any viewer sees them as note icons).

Select

The default tool. Click any annotation to select it — a dashed blue outline appears with resize handles on the right / bottom / bottom-right corners. Drag to move, drag a handle to resize, Delete to remove, F2 or Enter to edit text/notes.

Drag on empty space to region-select source PDF text — same behaviour as the Sel Text tool. On release you get the Copy / Replace / Translate menu.

Highlight Aa

Drag to paint a transparent colour block over text. The current colour applies.

Sticky Note

Click anywhere on a page; the same rich Text dialog used by Text stamps opens — set text, font family, size, weight (Regular / Medium / SemiBold / Bold), italic, underline, alignment, text colour, and background colour (defaults to yellow; pick None for transparent). On OK, a post-it style rectangle appears where you clicked, and the tool auto-reverts to Select with the new note selected so you can drag it or edit it further. On Cancel, the tool stays armed. Double-click an existing note to re-open the same dialog.

Save behaviour: sticky notes remain as native PDF text annotations after Save — any PDF viewer will show them as note icons. All styling (text colour, font, size, weight, italic, underline, alignment, background) is preserved via marker keys and re-materialises as an editable note when you reopen the file.

Text

The Text tool lives inside the toolbar's Text ▾ split-button (which also holds Tickmark, Crossmark, and Bullet — the button remembers whichever variant you picked last so a single click drops the same kind).

Click on a page and a dialog opens for:

  • Text (multi-line)
  • Font family (every font installed on Windows)
  • Size (points; snap-list + free-type)
  • Weight — Regular (400), Medium (500), SemiBold (600), Bold (700)
  • Italic, Underline
  • Alignment — Left / Center / Right / Justify
  • Text colour
  • Background colour — pick a swatch, hex value, or click None for transparent (the default for text stamps)

On OK, the stamp is dropped, the tool auto-reverts to Select, and the new stamp is selected. The next time you open the Text dialog for a new stamp it pre-fills with your last-used font, size, weight, and alignment. Double-clicking an existing stamp reopens its own settings, so you can't accidentally reformat a heading you set to Times 22.

Fine weights on save. The overlay preview renders Medium and SemiBold at their exact weight. On Save, PdfSharpCore's font model only has Regular / Bold — Medium and SemiBold both flatten as Bold; Regular flattens as Regular.

Callout

Callout is also on the Text ▾ split-button. Click the point you want to call out (the arrow tip); the same Text dialog opens for the callout box. On OK you get an editable box + a leader line + an arrowhead pointing at the click. Drag the box or the anchor handle independently (or drag them together with Select). Double-click to re-edit.

Callouts save as native PDF /FreeText annotations with a /IT /FreeTextCallout intent, so Acrobat, Chrome, and Foxit all render them as real callouts. An /ArtiMaxCallout marker key preserves the exact text colour and background so the callout returns as an editable overlay when you reopen the file.

Tick (✓), X (✗) & Bullet (•)

Three one-shot mark tools grouped on the Text ▾ split-button (below the Text and Callout entries). Ideal for filling scanned checkboxes and list forms. Click on the spot — a bold symbol drops at that point in the current colour. Unlike Text and Callout, these tools stay armed so you can drop several marks in a row without going back to the toolbar.

These marks are single-glyph text stamps under the hood. Double-click one to change size, font, or colour via the Text dialog.

Draw (ink)

Freehand drawing. Drag on a page to lay down a stroke in the current colour and thickness. Multiple strokes are separate annotations — pick each one with Select, delete or drag as needed.

Rectangle / Oval (outlined or filled)

Rectangle, Rectangle Filled, Ellipse, and Ellipse Filled all live on the toolbar's Shape ▾ split-button (which also holds Draw). Pick a variant; the button remembers your last choice for one-click reuse. Drag to draw the shape at the current colour and thickness. Filled variants ignore thickness and paint the interior.

Whiteout

Drag to cover an area with a solid white box. Useful for hiding a piece of text before dropping a Text stamp in its place. The whiteout has a faint dashed border while unsaved so you can see it; on Save it flattens to a plain white rectangle.

Redaction

Same as Whiteout but paints black instead of white. Also available from Tools → Redact Search Results to bulk-redact every current search hit.

Redaction here is visual — the covered text bytes remain in the content stream, so a determined attacker with a hex editor can still recover them. For true byte-level redaction you'd need a commercial PDF library. For casual "hide the address on a scan" use, this is fine.

Erase

Click any overlay annotation to remove it. Only affects unsaved overlays (once you Save, annotations become part of the PDF and you'd need Undo).

Select Text (region)

Drag over any block of text — with either the Sel Text tool or the normal Select tool on empty space. A menu offers:

  • Copy — puts the text on the clipboard.
  • Replace — whites out the region and opens the Text dialog pre-filled with the source text AND the source's detected font family, size, weight, italic, and bold. Font names get normalised to their Windows equivalents where needed (LiberationSans → Arial, DejaVuSans → Arial, etc.). The status bar shows the detection details (reported vs glyph-derived point size). Underline, alignment, and colour default to neutral values (off / left / black) because those aren't reliably per-glyph. Your toolbar's remembered font is not touched by Replace — it only changes when you create new text.
  • Translate — sends the region text to the MyMemory translation service. See Translate.
This is the "click a word, change it" workflow — a controlled substitute for Acrobat's inline-text edit.

Select Image (region)

Drag over any region — text, image, mixed — and choose:

  • Copy — puts the region on the clipboard as a raster image.
  • Save PNG — writes the region to a .png file.

Colour picker (toolbar)

The Colour: [swatch] ▾ block on the toolbar is a drop-down. Click the label, the swatch, or the chevron:

  • A palette of 12 common annotation colours drops down. Click one to set it as the current colour for all new annotations.
  • More Colours… at the bottom opens the full colour picker.

The current colour is saved per-user and restored on next launch.

Signatures

A signature is placed as a movable image annotation — drag and resize before Save, then it flattens onto the page.

  • Tools → Signatures… opens the Signature Library. Draw a new signature with the mouse, or load one from an image file. Named signatures are stored in %AppData%\PDFEditor\signatures\ and reused across sessions.
  • Draw signature lets you sketch a one-off signature that isn't saved.

Convert files to PDF

Drives Word / Excel / PowerPoint through COM when they're installed, and falls back to PdfSharpCore for images and text.

  • File → Convert to PDF… — single file. Result opens automatically.
  • File → Convert Multiple to PDF… — batch. Pick many files, pick an output folder; reports per-file success and failure.

Supported input types: .docx .doc .rtf .odt .xlsx .xls .xlsm .ods .pptx .ppt .odp .msg .oft .html .mht .jpg .png .bmp .gif .tif .txt .log .csv .xml .json .md.

Export from PDF

  • Export → As Word (.docx) — high fidelity via Word COM when installed, or text-only fallback via PdfPig when it isn't.
  • Export → As Excel (.xlsx) — text-only, one sheet per page.
  • Export → As HTML — a simple HTML rendering of the extracted text.
  • Export → As PNG images / As JPEG images — one image per page.

Edit in Word (round-trip)

Requires Word installed. This is the closest thing to Acrobat's inline text editor:

  1. Choose File → Edit in Word (round-trip)… The app exports the PDF to a temporary .docx and opens it in Word.
  2. Make your edits in Word and save.
  3. Back in PDF Editor, click Import in the dialog that stayed open. Word converts the docx back to PDF and replaces the current document bytes.
  4. Choose File → Save to persist.

OCR

Uses Tesseract. Each language needs a training-data file (e.g. eng.traineddata, ~22 MB) installed alongside the exe at tessdata\<lang>.traineddata.

Tools → OCR Languages is a submenu listing 14 common languages (English, French, German, Spanish, Italian, Portuguese, Dutch, Polish, Russian, Chinese Simplified & Traditional, Japanese, Korean, Arabic). Each row shows a ✓ next to the current language plus (current) or (installed) in the label.

  • Click an uninstalled language → prompt to download from the official GitHub repo straight into tessdata\. On success it becomes the new current language.
  • Click an installed language → set as current. Subsequent OCR commands use this language.
  • The current language is saved per-user and restored on next launch.
  • The first time you invoke any OCR command without the current language installed, the app offers to download it for you.
  • Manual install: drop any <lang>.traineddata file from github.com/tesseract-ocr/tessdata into tessdata\ next to PDFEditor.exe.

Then:

  • OCR Current Page — writes recognised text to the extract panel.
  • OCR All Pages → text file — batch-OCR everything and save to a .txt file (the PDF itself is left untouched).
  • Make Searchable PDF (OCR)… — rasterises each page and lays down an invisible text layer over it. Runs in-place: the OCR output loads back into memory (Ctrl+Z reversible), then Ctrl+S overwrites the original file. The result looks identical but is searchable / text-selectable in any viewer.
Make Searchable PDF guards against running on a vector text PDF: if the majority of pages already have ≥100 chars of embedded text, you get a warning before the rasterise-and-re-OCR step, because that would replace the accurate embedded text with less-accurate OCR output. Continue at your own discretion, or open a clean scan instead.

Translate

Sends text to MyMemory, a free public translation API. No signup, no API key — just plain HTTPS. Results appear in the extract panel.

Three ways to translate:

  • Tools → Translate… — whole current page (or tick "All pages" in the dialog).
  • Select Text tool → drag over a paragraph → the region action dialog now includes a Translate… button alongside Copy and Replace. The dialog opens with the selected text pre-set as the source; result shows original + translation side-by-side in the extract panel.
  • Both paths pop the same language picker (source + target). Choices persist across the session so you don't have to re-pick every time.

Supported languages include English, Spanish, French, German, Italian, Portuguese, Dutch, Polish, Russian, Turkish, Swedish, Greek, Hebrew, Arabic, Hindi, Chinese (Simplified), Japanese, Korean, Vietnamese, Thai and more.

Daily limit. MyMemory allows roughly 10 KB of text per IP address per day for anonymous use. Enough for reading pages ad-hoc; a whole 100-page document at once will hit the ceiling. If translation fails with a quota error, wait 24 h or try again from a different network. If your document is scan-only, run Tools → Make Searchable PDF first so there's extractable text.

Watermarks, headers & footers, Bates numbering

  • Tools → Watermark… opens the Watermark manager. It lists every watermark the app has previously applied to the current document with per-row Edit and Delete buttons; the same dialog has a form below the list for adding a new one (text, size, colour, opacity, angle). Edit / Delete rewind the app's undo stack to just before that watermark was added — clean, no opaque-white overpaint. Once a watermark is baked in beyond the undo horizon (save + close + reopen), the row shows baked in and the buttons disappear.
  • Add Headers & Footers… — six positions (three across the top, three across the bottom). Supports placeholders {page}, {total}, {date}, {filename}.
  • Add Bates Numbering… — prefix + starting number + digit width, placed in the bottom-right (or configurable position).
  • Insert Image on Current Page… — pick an image and a target rectangle; it's overlaid onto the page and flattened.

Fill forms

Tools → Fill Form… reads AcroForm fields from the PDF and shows them in a dialog. Edit values and click OK; the app writes them back to the PDF.

XFA forms (Adobe's XML-based dynamic forms) are not supported — most modern forms use AcroForm and work.

Security

  • Password Protect… — set a user password (open) and owner password (change), and toggle permissions: allow print, copy, annotations, or modification.
  • Remove Protection — clears the password / permissions from the current document (requires you to have opened it, so if a password is required, you'll be asked first).
  • Sanitize Metadata — strips Title / Author / Subject / Keywords / Creator / Producer and any XMP metadata block. Useful before sharing.

Compare two PDFs

Tools → Compare with another PDF… — opens a side-by-side viewer with the current document on the left and the picked file on the right, plus a per-page text-diff summary in the middle.

Clear Annotations

Tools → Clear Annotations… removes unsaved overlay annotations (Notes, Callouts, Text stamps, Ticks, Highlights, Ink, Rects, Ovals, Whiteouts). A dialog offers Current page or All pages. Either is undoable via Ctrl+Z.

Edit history

Edit → Edit History… shows every byte-level operation on this session's undo stack (watermarks, page ops, security, save-flatten, etc.) with a human-readable label. Select a row and click Revert to before selected to rewind the document to just before that operation. Overlay annotations are preserved across the rewind.

Themes

View → Theme → Dark / Light. The choice is stored in %AppData%\PDFEditor\theme.json and restored on next launch.

Customise the toolbar

View → Customise Toolbar… lets you toggle every toolbar entry on or off, and manage profiles. Every profile is a named set of visible buttons:

  • Create a "Reading" profile with only navigation and zoom.
  • Create a "Form-fill" profile with only Select, Text, Tick, X, and Signatures.
  • Switch profiles from the toolbar dropdown or the Customise dialog.

Profiles live in %AppData%\PDFEditor\toolbar.json.

Register as PDF handler

File → Register as PDF Handler… writes per-user (HKCU) registry entries that make PDF Editor appear in the Windows Open with list and the Settings → Default apps picker. No admin elevation required.

Windows blocks apps from silently claiming the default association, so after registering you still need to choose PDF Editor as your default once:

  • Right-click any .pdf → Open with → Choose another app → pick PDF Editor and tick Always use this app, OR
  • Settings → Apps → Default apps → search .pdf → pick PDF Editor.

File → Unregister as PDF Handler removes the entries. If you move the exe to a different location, unregister first, then register again from the new location so the recorded path is correct.

Recent files

File → Open Recent lists the last 10 documents. Selecting a missing file quietly removes it. Use Clear Recent to reset the list.

Undo

Ctrl+Z reverses:

  • Every kind of overlay annotation you can add — Whiteout, Rectangle, Ellipse (outlined or filled), Ink, Highlight, Sticky Note, Callout, Text Stamp, and the Tick / X / Bullet marks. One press = one annotation gone.
  • PDF-byte changes — watermark, headers & footers, Bates, page ops (rotate, delete, insert, extract, split, organise, crop), security (password protect, remove protection, sanitize metadata), and the save-flatten step.
  • Clear Annotations and Text Replace (whiteout + text stamp) as single operations.

Overlay undos are prioritised first — they don't touch the underlying PDF, so they're free. The byte-level undo history is capped at 20 entries; view or rewind to any point via Edit History.

Save behaviour

  • File → Save (Ctrl+S) writes overlay annotations into the PDF and saves back to the original path. Sticky notes and Callouts are preserved as native PDF /Text and /FreeText annotations (with marker keys so they round-trip back as editable overlays on next open); everything else is flattened.
  • File → Save As… writes to a new file. The new filename is added to the Recent Files list.
  • File in use. If Save fails because another app is holding the file open (Chrome, Acrobat, etc.), you're offered Yes / No: Yes retries after you close the other app; No keeps your changes in memory so you can retry manually.
  • Opening / closing / dropping a new file while there are unsaved changes prompts you to Save / Discard / Cancel. Cancel aborts the transition.
  • Print renders the PDF to the printer at 200 DPI. If the document contains sticky notes, you're asked whether to include them.

Tips & known limitations

  • File is locked while open. Other apps can read but not overwrite. Close the PDF to release the lock.
  • Text edit ≠ Acrobat reflow. This app does not reflow existing text bytes in place. Use Select Text → Replace for controlled inline edits.
  • Redaction is visual. Underlying text bytes remain — see Redaction.
  • XFA forms. Not supported. AcroForms are.
  • OCR needs training data. Add tessdata\eng.traineddata next to the executable — see OCR.
  • Word / Excel conversions use COM automation and require the corresponding Office app installed. Falls back to text-only when not.
  • Font retention for new text. The Text dialog remembers the last font family, size, weight, italic, underline, and alignment across new text stamps, sticky notes, and callouts. Double-clicking an existing stamp still uses that stamp's own settings. Select-Text → Replace ignores your remembered toolbar settings — it reads the source glyphs' font, size, weight, and italic straight from the PDF so the replacement matches the surrounding type.
